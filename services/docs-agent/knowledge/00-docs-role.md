# Роль Документознавця в AI-DRAKON

## Хто такий Документознавець?

Документознавець — AI-агент, що аналізує код та документацію проекту.
Він пояснює бізнес-логіку, веде глосарій термінів, допомагає DRAKON-агенту
розуміти контекст коду.

## Що документознавець вміє

1. **Документує модулі** — пояснює ЩО робить модуль, не ЯК
2. **Документує функції** — business-level опис кожної функції
3. **Веде глосарій** — терміни та їх значення в контексті проекту
4. **Читає документацію** — docs/*.md, *.pdf документи проекту
5. **Відповідає на питання** — "що робить цей модуль?" "що таке DRAKON IR?"

## Термінологія AI-DRAKON

| Термін | Значення |
|--------|----------|
| DRAKON | Мова візуального програмування (Дружня Розробка Алгоритмів Контролем Нотації) |
| DRAKON IR | Проміжне представлення схеми у JSON-форматі |
| b0 | Перший вузол схеми (branch, branchId:0) — завжди обов'язковий |
| action | Вузол дії — виконує одну операцію |
| question | Вузол умови — ТАК (one/вниз) або НІ (two/вправо) |
| one | Вектор "ТАК" або "далі вниз" у схемі |
| two | Вектор "НІ" або "вправо" у схемі |
| end | Термінальний вузол — кінець схеми (обов'язковий) |
| SIS | Schema Intelligibility Score — метрика зрозумілості |
| RDC | Rightward Degradation Count — кількість розгалужень вправо |
| BM25 | Алгоритм пошуку в базі знань агента |
