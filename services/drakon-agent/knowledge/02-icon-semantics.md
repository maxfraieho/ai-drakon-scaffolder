# Іконки DRAKON та їх семантика у drakonwidget.js IR

Екосистема DRAKON налічує 27 базових ікон та 21 макроікону. Для взаємодії між AST-аналізатором, LLM-агентом та рушієм drakonwidget.js у безсерверному середовищі використовується плоский JSON-словник ідентифікаторів (adjacency list), де топологічні зв'язки є неявними атрибутами вузлів.
У таблиці нижче наведено вичерпну таксономію підтримуваних типів (type property), їхнє семантичне призначення, правила підпису та відповідні конструкції Python AST, які запускають генерацію цих вузлів.


Офіційна назва (укр/eng)

## JSON тип
	Семантичне призначення
	Правило підпису

## Відповідна Python AST конструкція

## Заголовок / Header
	header
	Точка входу алгоритму (Begin) або заголовок паралельної гілки Силуету. Визначає назву функції.
	Ім'я процедури або назва логічного етапу (напр., UserAuthentication).
	ast.FunctionDef, ast.AsyncFunctionDef, ast.Module.

## Кінець / End
	end
	Логічне та фізичне завершення виконання алгоритму. Строго один вузол на весь граф. Не має вихідних зв'язків.
	"End" або "Кінець".
	Термінальна точка злиття для всіх ast.Return та ast.Raise.

## Дія / Action
	action
	Виконання імперативних команд, математичних обчислень або базових функцій. Розташовується виключно на вертикальній осі.
	Короткий дієслівний підпис або фрагмент коду (напр., x = 1 \n y = 2).
	ast.Assign, ast.AugAssign, ast.Expr, ast.Await, ast.ListComp.

## Запитання / Question
	question
	Логічне розгалуження (біфуркація). Має два виходи: one (вниз) і two (вправо). Лівобічні виходи заборонені.
	Булевий вираз або запитання, що обов'язково закінчується знаком ? (напр., is_valid?).
	ast.If, перевірка циклів ast.For/ast.While, синтетичний вузол після ast.Try.

## Гілка / Branch
	branch
	Макроструктурний заголовок паралельної гілки макрошаблону Силует. Точка навігації для передачі управління.
	Назва семантично незалежного блоку алгоритму (напр., Validation Phase).
	Блоки коду, виділені під час зниження цикломатичної складності   .

## Адреса / Address
	address
	Навігаційна команда переходу. Вказує виключно на ідентифікатор ікони-заголовка іншої гілки Силуету.
	Ім'я цільової гілки (посилання на існуючий branch).
	Стрибки між логічними блоками у декомпозованих алгоритмах.

## Вставка / Insertion
	insertion
	Синхронний виклик іншої DRAKON-схеми ("чорний ящик"). Потік зупиняється до завершення підпрограми.
	Назва зовнішньої функції та її аргументи.
	Зовнішні виклики функцій (ast.Call), визначені поза поточним модулем.

## Цикл / Loop Start
	loop_start
	Макроікона ітерації (For/While loop). Ініціалізує ітеративний кордон.
	Умова ітерації (напр., for item in collection).
	Початок ast.For або ast.While.

## Кінець циклу / Loop End
	loop_end
	Закриває цикл. Генерує зворотний покажчик next назад до loop_start.
	"End loop" або "Кінець циклу".
	Завершення блоку body у вузлах ast.For / ast.While.

## Полиця / Shelf
	shelf
	Багатоцільова ікона (присвоєння, наказ актору). Двокамерна структура.
	Верхня секція: змінна/актор. Нижня секція (secondary): значення/наказ.
	Специфічні DTO-присвоєння або RPC-виклики.

## Процес / Process
	process
	Запуск асинхронного фонового процесу без блокування поточного алгоритму.
	Команди управління асинхронністю: Start, Pause, Stop.
	ast.Call для фонових задач (напр., asyncio.create_task).
	Топологічні вказівники у словнику IR не використовують масиви ребер (edges). Зв'язки реалізуються виключно через атрибути one (наступний крок по основному вектору) та two (альтернативний або помилковий крок) всередині самого об'єкта вузла. Цей формат мінімізує структурні помилки LLM, дозволяючи моделі генерувати алгоритм ітеративно за час   .
