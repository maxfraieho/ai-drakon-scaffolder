## TASK-V2-07: Time Travel for Diagrams (Реалізовано)

Впроваджено повну функціональність Time Travel для діаграм:
1. **Авто-коміт (.drakon.json)**:
   - Додано автоматичне debounced збереження файлу `.drakon.json` до MinIO та Git (якщо налаштовано) після 30 секунд бездіяльності під час редагування.
2. **Timeline UI**:
   - Інтегровано компонент історії версій (`DiagramTimeline`) під канвасом.
3. **Diff-view між комітами**:
   - Додано кнопку порівняння (`GitCompare`) для будь-якої версії. При активації на канвасі підсвічуються додані (зеленим) та змінені (жовтим) вузли, а також виводиться сумарна інформація (added/modified/removed) з можливістю закрити порівняння.
4. **Restore (Відкат версій)**:
   - Функція відновлення тепер не просто оновлює стан віджета, але й негайно перезаписує поточний `.drakon.json` файл на сервері та робить коміт у Git, фіксуючи нову версію в IndexedDB.
