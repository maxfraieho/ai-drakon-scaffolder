## Інструкція з Використання PinchTab API

### 1. Визначення Активного Інстансу
Інстанси браузера створюються динамічно. Перед виконанням будь-яких дій спочатку надішліть `GET` запит до `/instances`, щоб отримати актуальний `id` активної вкладки:

```bash
curl -s http://192.168.3.184:9867/instances \
  -H "Authorization: Bearer 0117419fcfb5de5d82220c1f9da8de97"
```

### 2. Куленепробивна Навігація та Очищення localStorage
Щоб очистити `localStorage` або виконати `/eval` без помилки `404` на порожній сторінці `about:blank`, дотримуйтесь наступного порядку дій:
1. Виконайте `/navigate` на сторінку `/login` (або будь-який інший валідний маршрут сайту).
2. Зачекайте `2-3` секунди для завантаження DOM.
3. Лише після цього надсилайте запит `/eval` для очищення токенів або налаштування localStorage.

### 3. Робота з Введенням у React/Tailwind Форми
Для надійної взаємодії з полями вводу в React-компонентах:
* **НІКОЛИ** не використовуйте прямий `fill` без фокусу.
* **ЗАВЖДИ** спочатку імітуйте `click` по елементу (або фокусування), робіть паузу `200ms`, і лише потім виконуйте введення тексту `type`.

### 4. Отримання та Перевірка Скріншотів
* **КРИТИЧНО**: Ніколи не викликайте MCP screenshot інструменти, які повертають великі `base64` рядки прямо в текстовий контекст моделі. Це засмічує вікно контексту та призводить до перевищення ліміту токенів.
* **ПРАВИЛЬНИЙ ШЛЯХ**: Робіть скріншот через `curl` на сервері та зберігайте його як графічний файл у папку:
```bash
curl -s -X POST http://192.168.3.184:9867/<INSTANCE_ID>/screenshot \
  -H "Authorization: Bearer 0117419fcfb5de5d82220c1f9da8de97" \
  -o /tmp/pinchtab-tests/auth-page.png
```
Після цього за допомогою `scp` перемістіть його локально або використовуйте текстові семантичні ноди (`/snapshot`) для аналізу вмісту DOM.

## Часті Помилки та Pitfalls

1. **404 / 502 Bad Gateway при виклику /eval**:
   Виникає, коли Chromium відкритий на системній сторінці `about:blank`, яка не має доступу до `window.localStorage`.
   *Вирішення*: Завжди робіть перехід на реальну сторінку сайту перед очищенням або встановленням токенів через JavaScript.

2. **Зависання кліків на кнопках**:
   Деякі кнопки в інтерфейсі DrakonEditor є динамічними та перекриваються SVG-елементами під час масштабування полотна.
   *Вирішення*: Використовуйте семантичний клік по координатах центру або пошук за текстовим селектором кнопки з невеликою затримкою.

3. **Прострочений Cloudflare Pages API Token**:
   Якщо збірка застрягла у статусі `Auth error 10000`, перевірте термін дії токена деплою у налаштуваннях профілю Cloudflare.
