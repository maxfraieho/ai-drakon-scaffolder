## Призначення
Модуль відповідає за ініціалізацію та встановлення довірчих відносин між 
системою uav-watcher та серверами Telegram. Він забезпечує створення 
сесійного файлу, необхідного для подальшої роботи клієнта в автоматичному режимі.

## Архітектура
Модуль побудований на базі бібліотеки Telethon. Він використовує 
конфігураційні змінні середовища для ідентифікації застосунку в мережі 
Telegram та виконання процедури первинної авторизації користувача.

## Ключові функції
- `main()` — ініціалізує клієнт Telegram, виконує запит на авторизацію 
  за номером телефону та створює локальний файл сесії для збереження 
  стану авторизації.

## Потік виконання
1. Завантаження облікових даних (API ID, API HASH, номер телефону) з 
   файлу `.env`.
2. Створення екземпляра `TelegramClient` з ідентифікатором сесії `uav_watcher`.
3. Виконання інтерактивного процесу авторизації через `client.start()`.
4. Перевірка успішності авторизації шляхом отримання даних про поточного 
   користувача.
5. Завершення сесії та збереження отриманого токена доступу у файл.

## Залежності
- `telethon` — основна бібліотека для взаємодії з Telegram API.
- `python-dotenv` — для керування конфіденційними даними середовища.
