## Призначення
Цей модуль є центральним навігаційним хабом (MOC) проекту uav-watcher.
Він описує структуру системи моніторингу загроз, що базується на
аналізі даних з Telegram-каналів та геопросторових патернів.

## Архітектура
Система побудована на взаємодії між сервісом моніторингу загроз,
AI-консультантом Sharon та веб-інтерфейсом конфігурації. Вся інфраструктура
розгорнута на сервері під управлінням Alpine Linux.

## Ключові функції
- `uav_watcher.py` — забезпечує безперервний моніторинг загроз та
  класифікацію повідомлень через клієнт Telethon.
- `geo_monitor.py` — виконує зіставлення географічних патернів для
  генерації сповіщень про небезпеку.
- `shelter_search.py` — реалізує Telegram-бота для пошуку укриттів та
  забезпечення безпеки користувачів.
- `auth.py` — керує процесами автентифікації в системі.
- `web_config.py` — надає інтерфейс для налаштування параметрів системи.

## Потік виконання
Система збирає дані з 8+ Telegram-каналів, обробляє їх через модуль
моніторингу, зіставляє з географічними даними та надає результати
через AI-консультанта Sharon (FastAPI) або бот-інтерфейс.

## Залежності
- `Telethon` — для взаємодії з Telegram API.
- `FastAPI` — для роботи сервісу uav-consultant (Sharon).
- `Alpine Linux` — базове середовище виконання.
