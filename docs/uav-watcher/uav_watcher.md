## Призначення
Модуль `uav_watcher` відповідає за моніторинг Telegram-каналів у режимі реального часу для виявлення загроз, пов'язаних з БПЛА та ракетними атаками. Він виконує первинну фільтрацію повідомлень, класифікацію рівня загрози та керує логікою сповіщень для користувачів.

## Архітектура
Модуль побудований на базі асинхронної архітектури з використанням `Telethon` для взаємодії з Telegram. Система використовує механізми дедуплікації та троттлінгу (обмеження частоти сповіщень) для запобігання спаму, а також зберігає стан загрози у локальний JSON-файл для забезпечення стійкості до перезапусків.

## Ключові функції
- `score_proximity(text, city_keywords)` — оцінює ступінь небезпеки повідомлення за шкалою від 1 до 10 на основі близькості до цільового міста та ключових слів.
- `_infer_level(text, reason)` — визначає рівень загрози (1-3) на основі аналізу тексту повідомлення (наприклад, виявлення слів "вибух" або "над містом").
- `_save_threat_state(active)` / `_load_threat_state()` — забезпечують збереження та відновлення поточного статусу загрози, що дозволяє системі "пам'ятати" про небезпеку протягом 4 годин.
- `load_config()` — зчитує конфігураційні параметри для налаштування моніторингу.

## Потік виконання
1. **Ініціалізація**: Завантаження конфігурації та відновлення попереднього стану загрози з файлу.
2. **Моніторинг**: Асинхронне прослуховування Telegram-каналів через `Telethon`.
3. **Аналіз**: При отриманні повідомлення воно перевіряється за допомогою регулярних виразів (`_THREAT_PATTERNS`, `_ALLCLEAR_PATTERNS`).
4. **Класифікація**: Якщо повідомлення є загрозою, розраховується рівень небезпеки та оцінюється близькість до об'єкта моніторингу.
5. **Сповіщення**: Якщо загроза підтверджена, система надсилає повідомлення користувачу, враховуючи налаштовані інтервали затримки (cooldowns) для запобігання дублюванню.

## Залежності
- `Telethon` — для роботи з Telegram API.
- `httpx` — для виконання HTTP-запитів до зовнішніх сервісів (AI-проксі).
- `geo_monitor` — внутрішній модуль для побудови патернів локацій.
- `dotenv` — для керування змінними оточення.
