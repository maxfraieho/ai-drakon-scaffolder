## Призначення
Модуль `consultant` є центральним сервісом проекту uav-watcher, що реалізує 
інтерфейс взаємодії з користувачем через FastAPI. Він виступає "мозком" 
системи Sharon, забезпечуючи обробку запитів, доступ до бази знань та 
моніторинг потоку даних про загрози.

## Архітектура
Сервіс побудований на базі FastAPI та використовує асинхронний життєвий цикл 
(lifespan) для ініціалізації фонових процесів: спостерігачів за базою знань, 
аналізаторів ситуації та механізмів підсумовування каналів. Архітектура 
передбачає інтеграцію з графовим конвеєром обробки запитів (LangGraph).

## Ключові функції
- `chat(req)` — обробляє вхідні повідомлення користувача, запускаючи 
  графовий конвеєр для генерації відповіді з урахуванням контексту.
- `session_clear(req)` — видаляє історію діалогу для конкретної сесії, 
  що необхідно при зміні мови або скиданні контексту.
- `feed_stats()` — надає агреговану статистику по каналах спостереження, 
  включаючи кількість загроз та поточні підсумки.
- `health()` — перевіряє стан сервісу та доступність бази знань.

## Потік виконання
1. При старті сервіс ініціалізує базу знань та запускає фонові потоки 
   моніторингу ситуації та підсумовування даних.
2. Запит користувача через `/chat` передається до графового конвеєра, 
   який збагачує запит контекстом з бази знань.
3. Результат обробки повертається користувачу разом із метаданими про 
   використані розділи бази знань.
4. Фоновий процес постійно оновлює стан каналів, доступний через 
   ендпоінти `/feed`.

## Залежності
- `FastAPI` — веб-фреймворк для API.
- `knowledge_base` — модуль для роботи з базою знань та пошуку контексту.
- `pipeline.graph` — графовий рушій для обробки логіки діалогу.
- `memory` — підсистема для роботи з історією повідомлень та підсумками.
- `sharon.routes.pipeline_trace` — інструментарій для відстеження загроз.
