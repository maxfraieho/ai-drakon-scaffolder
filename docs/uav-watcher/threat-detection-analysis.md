## Модуль: Архітектура системи моніторингу загроз (Sharon)
Система Sharon забезпечує автоматизований моніторинг Telegram-каналів для виявлення загроз БПЛА та ракетних атак. Вона виконує фільтрацію повідомлень, геопросторову прив'язку та класифікацію небезпеки для сповіщення користувачів.

### Функції
- `classify_threat_level(text)` — визначає критичність загрози за шкалою 1-3.
    - Рівень 1: Потенційна загроза (розвідка, рух у напрямку області).
    - Рівень 2: Підтверджена загроза (курс на місто, активність у районі).
    - Рівень 3: Безпосередня небезпека (удар, вибухи, ціль у межах міста).
- `score_proximity(text, city_keywords)` — обчислює "вагу" близькості загрози.
    - Використовує лексичний аналіз: наявність назви міста + ключові слова напрямку (наприклад, "в бік", "наближається").
- `geo_monitor.build_pattern()` — формує регулярний вираз для пошуку координат.
    - Запитує дані через Overpass API для отримання актуальних меж міст та перетворює їх у пошукові патерни.

### Бізнес-логіка: Потік обробки
1. **Інгерція**: Отримання сирого тексту з Telegram-каналів.
2. **Класифікація**: 
    - Перевірка через `_THREAT_PATTERNS` (regex для типів БПЛА/ракет).
    - Перевірка через `_AIRARAID_PATTERNS` (статус повітряної тривоги).
3. **Гео-фільтрація**: Визначення близькості через `score_proximity`.
4. **Throttle**: Запобігання спаму шляхом групування повідомлень за часом та типом загрози.
5. **Сповіщення**: Відправка результату в канал сповіщень при перевищенні порогу важливості.

### Терміни предметної області
- `THREAT_PATTERNS` — набір регулярних виразів для ідентифікації об'єктів.
- `AIRARAID_PATTERNS` — патерни для розпізнавання офіційних оголошень тривоги.
- `Overpass API` — джерело гео-даних для динамічного оновлення зон моніторингу.

### Поточні обмеження
- **Залежність від формату**: Система чутлива до зміни стилю написання повідомлень у Telegram-каналах.
- **Хибні спрацювання**: Висока ймовірність помилок при згадці міст у контексті новин, а не реальної загрози.
- **Гео-точність**: Обмежена точністю координат, отриманих через Overpass API.
