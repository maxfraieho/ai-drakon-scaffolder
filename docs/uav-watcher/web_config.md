## Призначення
Модуль `web_config` забезпечує роботу веб-інтерфейсу для конфігурації 
системи `uav-watcher`. Він надає користувачеві доступ до бази знань 
щодо безпеки під час повітряних загроз та керування налаштуваннями 
через локальний HTTP-сервер.

## Архітектура
Модуль реалізований як легко вагова HTTP-служба на базі стандартної 
бібліотеки Python `http.server`. Він використовує багатопотоковість 
для обробки запитів та кешування даних для оптимізації відгуку інтерфейсу.

## Ключові функції
- `HTTPServer` — забезпечує роботу веб-сервера на порту 8422.
- `CHAT_KB` — словник, що містить інструкції з безпеки для різних 
  типів загроз (БПЛА, балістика, хімічна загроза тощо).
- `LOCKED_CHANNELS` — реєстр критично важливих каналів сповіщення, 
  що використовуються системою.
- `_shelter_cache` — механізм кешування даних про укриття для 
  швидкого доступу до інформації.

## Потік виконання
1. Ініціалізація сервера та завантаження конфігураційних даних.
2. Очікування вхідних HTTP-запитів від користувача.
3. Маршрутизація запитів до відповідних обробників (наприклад, 
   відображення інструкцій з `CHAT_KB`).
4. Повернення HTML-відповіді з актуальними даними конфігурації 
   або інструкціями безпеки.

## Залежності
- `http.server`, `threading` — для забезпечення роботи мережевого 
  інтерфейсу.
- `urllib` — для парсингу URL та запитів.
- `json`, `os`, `re` — для обробки конфігураційних даних та 
  текстового контенту.
