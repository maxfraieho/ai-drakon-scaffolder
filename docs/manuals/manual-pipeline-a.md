# Мануал: Pipeline A — Аналіз коду та генерація DRAKON IR

## 1. Призначення та архітектура

**Pipeline A** (Code-to-IR) — це асинхронний інженерний конвеєр платформи **AI-DRAKON**, призначений для статичного та семантичного аналізу вихідного коду (наразі підтримується Python, з розширенням на JavaScript/TypeScript) та його автоматичного перетворення у проміжне представлення **DRAKON IR** (Intermediate Representation).

Цей пайплайн вирішує наступні завдання:
- Парсинг вихідного коду в абстрактне синтаксичне дерево (AST).
- Виділення керуючих конструкцій (умовні розгалуження, цикли, послідовні дії).
- Генерація стандартизованого графа логіки у форматі DRAKON IR JSON.
- Візуалізація отриманого графа в інтерактивному DRAKON-редакторі.

### Задіяні агенти:
1. **Architect Agent** (порт `:8766`) — аналізує високорівневу структуру коду, визначає ключові функції, класи та модулі.
2. **Drakon Agent** (порт `:8771`) — відповідає за безпосередню трансляцію AST-структур у вузли та ребра DRAKON IR відповідно до правил стандарту ДРАКОН.

## 2. Запуск та взаємодія через веб-інтерфейс

Щоб виконати аналіз коду через графічний інтерфейс користувача:

1. **Авторизуйтеся** в системі під своїм обліковим записом.
2. Перейдіть у розділ **Код** (роут `/code`) за допомогою лівого навігаційного меню.
3. У текстовому полі вводу (підтримується Monaco Editor) введіть або вставте ваш вихідний код. Наприклад:
   ```python
   def check_temperature(t):
       if t > 100:
           return "Гаряче"
       elif t < 0:
           return "Замерзання"
       else:
           return "Нормально"
   ```
4. Натисніть кнопку **Аналізувати** (кнопка `ref=e39` або з аналогічним текстом).
5. Після запуску з'явиться індикатор завантаження `Loading...`. Процес аналізу за участю LLM-агентів у хмарі може тривати від 10 до 30 секунд.
6. Після завершення аналізу система автоматично перенаправить вас у розділ **Схеми** (`/diagrams`), де відкриється згенерована DRAKON-схема з назвою функції `check_temperature`, розбита на візуальні блоки (Початок, Вибір, Дія, Кінець).

## 3. Запуск через розробницький MCP-інтерфейс (API)

Для інтеграції Pipeline A в зовнішні інструменти розробника (наприклад, CLI або розширення VS Code) використовується протокол **MCP (Model Context Protocol)**.

### Крок 1. Отримання списку інструментів
Виконайте запит для верифікації наявності інструменту `pipeline.analyze`:
```bash
curl -s -X POST https://drakon-mcp-worker.maxfraieho.workers.dev/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer drakon-mcp-2026" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
```

### Крок 2. Виклик інструменту аналізу коду
Надішліть POST-запит до інструменту `pipeline.analyze` з кодом для аналізу:
```bash
curl -s -X POST https://drakon-mcp-worker.maxfraieho.workers.dev/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer drakon-mcp-2026" \
  -d '{
    "jsonrpc": "2.0",
    "id": 2,
    "method": "tools/call",
    "params": {
      "name": "pipeline.analyze",
      "arguments": {
        "code": "def process_data(x):\n    if x % 2 == 0:\n        return True\n    return False",
        "language": "python",
        "file_path": "process.py"
      }
    }
  }'
```

## 4. Очікуваний результат (DRAKON IR)

Успішний запуск Pipeline A повертає структуру DRAKON IR JSON наступного формату:

```json
{
  "type": "drakon-ir",
  "version": "1.0",
  "nodes": [
    { "id": "b0", "type": "start", "title": "START: process_data(x)" },
    { "id": "n1", "type": "question", "title": "x % 2 == 0?" },
    { "id": "n2", "type": "action", "title": "return True" },
    { "id": "n3", "type": "action", "title": "return False" },
    { "id": "n4", "type": "end", "title": "END" }
  ],
  "edges": [
    { "from": "b0", "to": "n1" },
    { "from": "n1", "to": "n2", "label": "YES" },
    { "from": "n1", "to": "n3", "label": "NO" },
    { "from": "n2", "to": "n4" },
    { "from": "n3", "to": "n4" }
  ]
}
```

## 5. Типові помилки та їх вирішення

### 1. Помилка `Connection refused / Bad Gateway (502)`
* **Причина**: Віддалений MCP-воркер або сервіс Drakon Agent на порту `:8771` тимчасово перезавантажується або недоступний через ліміти запитів.
* **Вирішення**: Зачекайте 10-15 секунд та повторіть запит. Перевірте статус сервісів через розділ `Settings` -> `Worker Status`.

### 2. Синтаксична помилка парсингу (Syntax Error)
* **Причина**: Надісланий Python-код містить грубі порушення синтаксису (наприклад, нерівні відступи `IndentationError` або пропущені двокрапки).
* **Вирішення**: Переконайтеся, що код є робочим та успішно компілюється локальним інтерпретатором Python перед відправкою на аналіз.
