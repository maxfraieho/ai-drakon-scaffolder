# Мануал: Pipeline A — Аналіз коду та генерація DRAKON IR

## 1. Призначення та архітектура

**Pipeline A** (Code-to-IR) — це асинхронний інженерний конвеєр платформи **AI-DRAKON**, призначений для статичного та семантичного аналізу вихідного коду (Python, JS/TS) та його автоматичного перетворення у проміжне представлення **DRAKON IR**.

### Задіяні агенти:
1. **Architect Agent** — аналізує високорівневу структуру, визначає ієрархію та модульність.
2. **Drakon Agent** — виконує безпосередню трансляцію AST або текстових описів у вузли DRAKON IR.

Обидва агенти працюють у середовищі Cloudflare Workers на базі Flue Runtime.

---

## 2. Запуск через веб-інтерфейс

1. **Авторизуйтеся** в системі.
2. Перейдіть у розділ **Код** (`/code`).
3. Вставте код у редактор (використовує Monaco Editor).
4. Натисніть кнопку **Аналізувати**.
5. Після завершення процесу система виведе `toast.success` з посиланням **"Відкрити схему"**, яке перенаправить вас у розділ `/diagrams`.

---

## 3. Запуск через MCP-інтерфейс (API)

Для інтеграції використовується Cloudflare Worker: `https://drakon-antigravity-worker.maxfraieho.workers.dev/v1/`.

### Виклик аналізу:
```bash
curl -X POST https://drakon-antigravity-worker.maxfraieho.workers.dev/v1/pipeline/analyze \
  -H "Authorization: Bearer ${PROXY_TOKEN}" \
  -d '{"source_code": "def test(): pass"}'
```
Після отримання `job_id` використовуйте `GET /pipeline/status/{id}` для перевірки готовності.

---

## 4. Специфікація DRAKON IR

Кожна схема — це JSON-об'єкт:
- `name` (string), `params` (string), `items` (object).
- **Обов'язкові вузли**:
    - `b0`: `{"type":"branch","branchId":0,"one":"<id>"}`
    - `end`: `{"type":"end"}`
- **Вузли**:
    - `action`: `{"type":"action","content":"...", "one":"<id>"}`
    - `question`: `{"type":"question","content":"...?", "one":"<так>", "two":"<ні>"}`

---

## 5. Відомі обмеження та вирішення проблем

### Типові помилки:
1. **502 Bad Gateway / Cloudflare WAF**: Перевірте статус воркера та наявність User-Agent у запитах. Переконайтеся, що налаштовані правильні URL воркерів у Налаштуваннях.
2. **Syntax Error**: Переконайтеся, що вихідний код є валідним та не містить синтаксичних помилок перед запуском аналізу.
3. **Некоректна візуалізація**: Перевірте наявність обов'язкових вузлів `b0` та `end` у структурі JSON.
