# Мануал: Pipeline B — Генерація коду з DRAKON IR

## 1. Призначення та архітектура

**Pipeline B** (IR-to-Code) — це зворотний інженерний конвеєр платформи **AI-DRAKON**, призначений для трансляції візуальних логічних схем (представлених у форматі **DRAKON IR JSON**) у повноцінний, структурований вихідний код на обраній мові програмування.

Цей пайплайн вирішує наступні завдання:
- Трансляція двовимірних керуючих графів (ДРАКОН-схем) у лінійний структурований код.
- Генерація семантично чистого коду без дублювання логіки та "спагеті-коду".
- Підтримка цільових мов: **Python** та **JavaScript/TypeScript**.

### Задіяні агенти:
1. **Drakon Agent** (порт `:8771`) — зчитує геометрію графа, перевіряє правильність з'єднань, усуває висячі ребра та формує логічні блоки.
2. **Architect Agent** (порт `:8766`) — відповідає за фінальну оптимізацію коду, дотримання код-стайлу (PEP8 для Python, ES6 для JS) та додавання автоматичної документації (docstrings).

## 2. Запуск та взаємодія через веб-інтерфейс

Щоб згенерувати код із візуальної ДРАКОН-схеми:

1. Відкрийте потрібну схему в розділі **Схеми** (роут `/diagrams`).
2. Внесіть необхідні зміни у структуру вашої схеми (додайте блоки дії, умовні запитання або цикли).
3. Перейдіть на вкладку **Код** або скористайтеся панеллю швидкої генерації праворуч.
4. Натисніть кнопку **Згенерувати** або **Експорт коду** (у системі це представлено кнопками `Pseudocode`, `Генерувати JSON` (`ref=e132`) або аналогічними UI елементами експорту).
5. Результат генерації буде миттєво виведено в інтерактивному вікні редактора коду. Ви зможете скопіювати згенерований код або зберегти його безпосередньо у підключений репозиторій GitHub через інтерфейс налаштувань.

## 3. Запуск через розробницький MCP-інтерфейс (API)

Для виклику Pipeline B програмним шляхом використовується інструмент `pipeline.generate` через протокол **MCP**.

### Приклад POST-запиту:
Надішліть структуру DRAKON IR і вкажіть цільову мову програмування:

```bash
curl -s -X POST https://drakon-mcp-worker.maxfraieho.workers.dev/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer drakon-mcp-2026" \
  -d '{
    "jsonrpc": "2.0",
    "id": 12,
    "method": "tools/call",
    "params": {
      "name": "pipeline.generate",
      "arguments": {
        "target_language": "python",
        "ir": {
          "type": "drakon-ir",
          "version": "1.0",
          "nodes": [
            { "id": "b0", "type": "start", "title": "START: is_positive(num)" },
            { "id": "n1", "type": "question", "title": "num > 0?" },
            { "id": "n2", "type": "action", "title": "print(\"Positive\")" },
            { "id": "n3", "type": "action", "title": "print(\"Negative\")" },
            { "id": "n4", "type": "end", "title": "END" }
          ],
          "edges": [
            { "from": "b0", "to": "n1" },
            { "from": "n1", "to": "n2", "label": "YES" },
            { "from": "n1", "to": "n3", "label": "NO" },
            { "from": "n2", "to": "n4" },
            { "from": "n3", "to": "n4" }
          ]
        }
      }
    }
  }'
```

## 4. Очікуваний результат (Згенерований код)

За результатом виклику API Pipeline B поверне семантично чистий код:

```python
def is_positive(num):
    """
    Generated automatically by AI-DRAKON Pipeline B.
    """
    if num > 0:
        print("Positive")
    else:
        print("Negative")
```

## 5. Обмеження та типові помилки

### 1. Помилка dangling pointer (висяче ребро)
* **Симптоми**: Валідатор видає помилку: `Validation Error: Node 'n2' has no exit edge`.
* **Причина**: В ДРАКОН-схемі один із блоків дії або запитання не з'єднаний лінією з іншим блоком (немає вихідного ребра).
* **Вирішення**: Перевірте схему у візуальному редакторі та переконайтеся, що всі елементи мають вихідні стрілки, які врешті-решт ведуть до блоку `End` (Кінець).

### 2. Непідтримувана цільова мова
* **Симптоми**: Помилка `Invalid target language: golang`.
* **Вирішення**: Наразі платформа офіційно підтримує генерацію лише для `python` та `javascript`. Змініть аргумент `target_language` на один із підтримуваних.
