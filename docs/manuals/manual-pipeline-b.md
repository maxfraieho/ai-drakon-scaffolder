# Мануал: Pipeline B — Генерація коду з DRAKON IR

## 1. Призначення та архітектура

**Pipeline B** (IR-to-Code) — це ключовий конвеєр платформи **AI-DRAKON**, призначений для трансляції візуальних логічних схем (формат **DRAKON IR JSON**) у структурований вихідний код.

### Задіяні агенти:
1. **Drakon Agent**: валідація геометрії графа, перевірка цілісності з'єднань, формування логічних блоків.
2. **Architect Agent**: оптимізація коду, дотримання код-стайлу, додавання документації.

---

## 2. Запуск та взаємодія через веб-інтерфейс

1. Відкрийте схему в розділі `/diagrams`.
2. Внесіть зміни (блоки `action`, `question`, `end`).
3. Натисніть кнопку **"Аналізувати"**.
4. Після успішного виконання з'явиться `toast.success` з посиланням **"Відкрити схему"**.
5. Результат генерації відображається в інтерактивному редакторі коду.

---

## 3. Запуск через розробницький MCP-інтерфейс (API)

Для програмного виклику використовується інструмент `pipeline.generate` через **Cloudflare Worker** (`https://drakon-mcp-worker.maxfraieho.workers.dev/v1/`).

### Робочий процес:
1. **POST** `/pipeline/analyze` з тілом `{"source_code": "..."}` повертає `job_id`.
2. **GET** `/pipeline/status/{id}` для отримання результату.
3. **Важливо**: При обробці даних використовуйте `TextDecoder('utf-8').decode(Uint8Array.from(atob(data), c => c.charCodeAt(0)))` для коректної обробки UTF-8.
4. **Безпека**: Завжди використовуйте `PROXY_TOKEN` з ENV-змінних, не хардкодьте токени.

### Доступні MCP інструменти:
- `pipeline.generate`: основна генерація коду.
- `files.read` / `files.list`: доступ до файлової структури проекту.
- `resources`: робота з контекстом проекту.

---

## 4. Очікуваний результат (DRAKON IR структура)

Кожен вузол має відповідати специфікації:
- `b0`: `{type:"branch", branchId:0, one:"<next>"}` (обов'язково).
- `action`: `{type:"action", content:"...", one:"<next>"}`.
- `question`: `{type:"question", content:"...?", one:"<yes>", two:"<no>"}`.
- `end`: `{type:"end"}` (обов'язково).

---

## 5. Відомі обмеження та типові помилки

### 1. BUG-6: Відсутність inline-чату
Наразі в розділі `/agents` відсутній inline-чат. Для взаємодії з агентом переходьте безпосередньо до секції `/chat`.

### 2. Помилка dangling pointer
* **Симптоми**: `Validation Error: Node 'n2' has no exit edge`.
* **Причина**: Відсутність вихідного ребра.
* **Вирішення**: Переконайтеся, що всі шляхи ведуть до вузла `end`.

### 3. Непідтримувана мова
* **Причина**: Запит до непідтримуваної мови (наразі лише `python` та `javascript`).
