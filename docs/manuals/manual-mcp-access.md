# Мануал: MCP-доступ для розробників та зовнішніх сервісів

## 1. Протокол MCP та авторизація

Платформа **AI-DRAKON** надає розробникам та зовнішнім інтелектуальним агентам можливість програмного керування ресурсами через протокол **MCP (Model Context Protocol)**. Сервіс працює поверх HTTP/SSE.

* **MCP Endpoint**: `https://architect-agent-flue.maxfraieho.workers.dev/mcp`
* **Health Check**: `https://architect-agent-flue.maxfraieho.workers.dev/health`

### Параметри авторизації:
Кожен запит повинен містити заголовок авторизації `Authorization: Bearer <TOKEN>`. Токен налаштовується в конфігурації оточення воркера.

> [!IMPORTANT]
> **УВАГА (Cloudflare WAF):**
> Для уникнення автоматичних блокувань (HTTP 403) завжди додавайте реалістичний заголовок `User-Agent`.

---

## 2. Основні функції та інструменти

Воркери Flue надають такі можливості через API та MCP-інтерфейс:

### ⚙️ Інженерні конвеєри (Pipelines)
* **`GET /tools`**: Динамічний реєстр доступних дій воркера.
* **`GET /graph-pipelines`**: Отримання списку ДРАКОН-пайплайнів.
* **`GET /graph-pipelines/{name}/execute`**: Запуск конвеєра з трансляцією логів через SSE.

### 📁 Документація та База знань
* **`GET /docs` (колишній `/notes`)**: Читання та робота зі структурою документації з підключеного GitHub-репозиторію.
* **`github_write_file`**: Прямий запис та комміт оновлених документів у репозиторій.

### 🤖 Інтерактивна взаємодія
* **`POST /v1/agents/{id}/chat`**: Прямий чат з AI-агентами (`architect`, `drakon`, `docs`).

---

## 3. Вирішення проблем
* **502 Bad Gateway / Connection Refused**: Перевірте правильність заповнення URL-адрес воркерів у розділі **Налаштування** (`/settings`) вашого клієнта.
* **Помилки авторизації**: Перевірте наявність та правильність передачі токена в заголовках.
