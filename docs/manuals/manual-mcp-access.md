# Мануал: MCP-доступ для розробників та агентів

## 1. Протокол MCP та авторизація

Платформа **AI-DRAKON** надає розробникам та зовнішнім інтелектуальним агентам можливість програмного керування ресурсами через протокол **MCP (Model Context Protocol)**. Сервіс працює поверх HTTP/SSE.

* **MCP Endpoint**: `https://drakon-mcp-worker.maxfraieho.workers.dev/v1/`
* **Health Check**: `https://drakon-mcp-worker.maxfraieho.workers.dev/health`

### Параметри авторизації:
Кожен запит повинен містити заголовок авторизації. Використовуйте `PROXY_TOKEN` з налаштувань середовища (fallback на `drakon-mcp-2026` лише для локальної розробки).
* **Header**: `Authorization: Bearer <TOKEN>`

> [!IMPORTANT]
> **УВАГА (Cloudflare WAF):**
> Для уникнення блокувань (HTTP 403) обов'язково додавайте реалістичний `User-Agent`. При обробці відповідей використовуйте `TextDecoder('utf-8')` для коректного відображення символів (UTF-8 fix).

## 2. Групи MCP-інструментів

### 📂 Група 1: `docs.*` (База знань)
* **`docs.query`**: DQL-запит до бази. Аргумент: `query`.
* **`docs.read`**: Читання файлу. Аргумент: `path`.
* **`docs.wikilink`**: Розкриття вікілінків. Аргумент: `title`.
* **`docs.backlinks`**: Пошук посилань. Аргумент: `path`.

### 📂 Група 2: `files.*` (Робота з файловою системою)
* **`files.list`**: Отримання структури проекту.
* **`files.read`**: Читання вмісту файлу за абсолютним шляхом.
* **`files.write`**: Запис даних у файл.

### ⚙️ Група 3: `pipeline.*` (Інженерні конвеєри)
Використовуйте асинхронну модель:
1. **`pipeline.analyze`**: Запуск аналізу. Повертає `job_id`.
2. **`pipeline.status`**: Опитування статусу за `job_id`.
3. **`pipeline.generate`**: Генерація коду з IR.

*Примітка:* Після успішного аналізу в UI з'являється toast-повідомлення з посиланням "Відкрити схему".

### 📊 Група 4: `diagram.*` (CRUD схем)
Інструменти для маніпуляції DRAKON-схемами (JSON IR).
* **`diagram.list`**, **`diagram.create`**, **`diagram.read`**, **`diagram.update`**, **`diagram.delete`**.

### 🤖 Група 5: `agent.*` (Інтелектуальні агенти)
* **`agent.chat`**: Взаємодія з агентами (`architect`, `docs`, `drakon`).
  * *Аргументи*: `agent`, `message`, `context`.
  * *Відповідь*: об'єкт з полем `reply` та опціональним `suggested_mutations`.

## 3. Відомі обмеження та баги
* **BUG-6 (Agent Studio)**: Вбудований чат (inline chat) наразі недоступний. Для взаємодії з агентами використовуйте виділену секцію `/chat`.
* **Architect Agent**: Повертає `suggested_mutations` для автоматичного застосування змін у схемах.
