## Рекомендації

### 1. Оновлення посібників конвеєрів (Pipeline A & B)
- Переписати опис взаємодії з UI у [[manuals/manual-pipeline-a]] та [[manuals/manual-pipeline-b]], прибравши застарілі посилання на роут `/code` та окремі кнопки, які були об'єднані в єдиний інтерактивний Workspace.
- Оновити приклад MCP API-запитів відповідно до актуальної схеми викликів та параметрів `cloudflare-worker/`.
- Додати примітки про те, що порти є внутрішніми та в продакшні сервіси працюють як Cloudflare Workers.

### 2. Виправлення посібника Agent Studio
- Чітко задокументувати відомі обмеження інтерфейсу (включаючи BUG-6 щодо неможливості ведення чату безпосередньо у `/agents`).
- Актуалізувати термінологію вузлів DRAKON IR (замінити `Start` на `b0`, уточнити правила для `action` та `question`).

### 3. Оновлення інструкції доступу до MCP
- Замінити застарілі URL воркерів на актуальні шляхи.
- Рекомендувати використання змінних середовища для автентифікації замість відкритих токенів.
- Додати повний список актуальних інструментів, включаючи файлові інструменти `files.*` та концепцію `resources` для передачі контексту коду.
