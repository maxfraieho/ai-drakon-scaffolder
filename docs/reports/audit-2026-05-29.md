## /docs:
Показує генератор документації, список документів та граф. В розділі документів відображаються як загальні файли проекту AI-DRAKON, так і специфічні документи по `sharon-uav` (зокрема: `Sharon UAV — Handoff: Підключення до AI-DRAKON Framework` у секції `handoff` та `Demo: Sharon UAV Threat Classifier` у секції `reports`).

## /code:
Порожньо (показує дефолтний файл `untitled.py` та текстову область редактора). Робота з кодом заблокована через відсутність інтеграції з GitHub. Відображаються попередження "Налаштуйте GitHub у Settings" та неактивна кнопка "Потрібен GitHub токен в Settings".

## Висновок:
Основні сторінки та інтерфейси (/agents, /docs) завантажуються та відображаються коректно. Для функціонування сторінки /code необхідно налаштувати GitHub токен у конфігурації платформи.
